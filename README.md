# Mini Message Board

A full-stack mockup implementation of a simple message board. Contains a homepage which displays all the messages, each containing a button which displays the message information when clicked. Messages can be added to the board through the Add Message screen after clicking on the link in the nav bar. 

App deployed via Render [here](https://message-board-0jqz.onrender.com/)

## Tech Stack

* Express (Node JS)
* EJS
* Vanilla CSS

## What I Learned

This was my first proper Express project, as well as my first project using EJS. I learned about:

* Routing via Express
* Using request parameters for dynamic webpages
* The basics of EJS
* Using 'include' to pass data to templates
* Using post requests to upload data
* Reviewing vanilla CSS
